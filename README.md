# Automated-Mapping-of-Handwritten-Prescription-Images
I predict the PHY_ID for each prescription by first extracting robust visual embeddings from a pretrained Vision–Language model (CLIP, ViT‑base) using two views of each page: the full image (handwriting + layout) and a header crop (top ~25%, which captures letterheads, logos and doctor pads). I concatenate those CLIP embeddings and use a simple, non‑parametric K‑Nearest‑Neighbors (k=3, cosine) classifier on the fused embeddings — KNN worked best on this small, imbalanced dataset. For confidence I compute the mean distance to the top‑3 neighbors: if the mean distance is below a validated threshold the prediction is auto‑accepted; otherwise the case is routed to human review. I experimented with OCR (EasyOCR) and an MLP head on CLIP, but handwritten OCR was noisy and the MLP underperformed; KNN on frozen CLIP embeddings gave the best, most interpretable results. The system is explainable because every prediction is supported by its nearest neighbor images and distances, enabling quick human verification and a safe human‑in‑the‑loop deployment.
